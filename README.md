# BeatArena MVP

Платформа матчей для музыкальных продюсеров: сервер собирает 10 игроков, создаёт комнату и назначает всем один случайный YouTube-трек для сэмплирования.

## Запуск

Нужен Node.js 24+.

```bash
cd /Users/abdyqasym/Projects/beat-arena
npm install
npm run dev
```

Откройте `http://localhost:5173`. Backend работает на `http://localhost:3001`.

Команда `npm run dev` запускает оба процесса:

- Vite/React frontend;
- Express + Socket.IO backend.

## Первый тест

1. Зарегистрируйте аккаунт.
2. Нажмите «Найти матч».
3. Нажмите «Заполнить тестовыми игроками», чтобы локально не создавать ещё девять аккаунтов.
4. Сервер создаст матч, покажет десять игроков и общий YouTube-трек.
5. Загрузите MP3/WAV до завершения 30-минутного таймера.
6. В профиле можно изменить имя, город, био и аватар.

Тестовая кнопка недоступна при `NODE_ENV=production`.

## YouTube Data API

Без API-ключа приложение берёт трек из небольшого демонстрационного пула. Для поиска новых треков:

1. Создайте проект в Google Cloud.
2. Включите YouTube Data API v3.
3. Создайте API key.
4. Скопируйте `.env.example` в `.env`.
5. Добавьте ключ:

```env
YOUTUBE_API_KEY=ваш_ключ
```

Backend использует официальный `search.list` с фильтрами `type=video`, `videoCategoryId=10` (Music), `videoLicense=creativeCommon`, `videoEmbeddable=true` и `safeSearch=strict`. Из найденных музыкальных видео сервер выбирает случайное.

Важно: YouTube API находит видео, но не даёт права на использование записи. Для публичных релизов нужен разрешённый/лицензированный каталог сэмплов. Поисковые запросы MVP намеренно ориентированы на royalty-free и Creative Commons контент.

## Что реализовано

- регистрация и вход;
- безопасное хеширование паролей через `scrypt`;
- серверные сессии;
- редактирование профиля, био, города и аватара;
- SQLite-база пользователей, очередей, матчей, работ и голосов;
- realtime matchmaking через Socket.IO;
- автоматическое создание комнаты при наборе 10 игроков;
- случайное музыкальное видео YouTube через Data API или музыкальный fallback-пул;
- серверный 30-минутный таймер;
- автоматическое исключение игроков без загруженной работы;
- загрузка и замена MP3/WAV до 30 МБ;
- восстановление активного матча после перезагрузки;
- калибровка, лидерборд и адаптивный интерфейс.

## Структура

```text
src/                 React frontend
server/index.js      Express API
server/auth.js       регистрация, вход, сессии
server/db.js         SQLite и схема данных
server/matchmaking.js Socket.IO очередь и создание матчей
server/youtube.js    выбор общего трека
```

Локальная база создаётся автоматически в `server/data/beat-arena.db` и не попадает в Git.
